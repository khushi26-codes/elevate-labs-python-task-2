# Task 2 - To-Do List Application

This is a simple console-based To-Do List application made in Python as part of Elevate Labs Internship.

## Objective
To create a Python program that allows users to manage their daily tasks.

## Features
- View all tasks
- Add new task
- Delete / Complete task
- Data saved in tasks.txt (persistent storage)
- Simple console menu

## Tools Used
- Python
- IDLE

## How to Run
1. Run the file: `python todo.py`
2. Choose from menu:
   - 1 for View Tasks
   - 2 for Add Task
   - 3 for Delete Task
   - 4 for Exit

## Files
- todo.py - Main Python code
- tasks.txt - Auto-generated file that stores tasks
